# A.MORE — дизайн-система интерфейса

Этот файл — источник правды по внешнему виду A.MORE. Положи его в корень репозитория
`aliseemore-dotcom/a.sha.platform` (рядом с `CLAUDE.md`) и сверяйся с ним при любой правке
интерфейса: новых экранах, компонентах, стилях, диалогах.

Основа — брендбук «Soft Editorial Glass v1.1» (гарнитура Involve, шкала отступов, скругления,
правила стекла и статусов). Поверх него приняты решения, описанные ниже: облегчённые
начертания, тонкие линии, палитра «Слива» вместо чёрного/красного/оранжевого, обложки
проектов и компактная раскладка. Если брендбук и этот файл расходятся — прав этот файл
(список расхождений в конце).

## 1. Задача внедрения

В архиве `amore-design-v2` лежат готовые файлы. Порядок работы:

1. **Стили.** Заменить `web/styles/tokens.css` и `web/styles/app.css` файлами из `styles/`.
2. **Обложки.** Скопировать `images/covers/*.jpg` в `web/images/covers/` (проверить, что
   сервер отдаёт `/images/covers/...` как статику, так же как `/fonts/`).
3. **JS.** Перенести из `source/`:
   - `source/ui/covers.js` → `web/js/ui/covers.js` (новый файл);
   - `source/ui/components.js` → `web/js/ui/components.js` (карточка использует обложки);
   - `source/views/overview.js` → `web/js/views/overview.js` (новая шапка-hero и две колонки).
   Файлы сделаны от ветки `claude/count-create-documents-41di1x`. Если в репозитории эти файлы
   с тех пор менялись — не затирать, а перенести только изменения (см. `ИЗМЕНЕНИЯ.md`
   и дифф с исходниками из первого архива).
4. **Причесать `app.css`.** В конце файла есть блоки «v2.2» и «v2.3» — это переопределения,
   дописанные поверх старых правил. Перенести их значения в исходные правила соответствующих
   компонентов и удалить дубли, чтобы у каждого компонента было одно место в файле. Визуально
   ничего не должно измениться — сверить скриншотами до/после.
5. **Проверить экраны** (desktop 1440 и мобильный 390): вход, «Мои мероприятия», обзор
   проекта, все задачи, смета, команда, подрядчики, диалоги создания/редактирования свадьбы
   и подрядчика. Отдельно: проект без даты, проект с датой «только месяц», архивный проект,
   проект с собственным `coverUrl`, пустые состояния.
6. Сделать скриншоты тех же экранов, что в `screenshots/` первого архива, и приложить к PR.

## 2. Принципы

- **Тихо и тонко.** Интерфейс — рабочий инструмент. Линии тонкие и полупрозрачные, веса
  лёгкие, тени почти не используются. Выразительность дают фото обложек и крупная дата,
  а не рамки, заливки и жирный шрифт.
- **Эмоциональный и рабочий режимы (брендбук).** Сверху экрана — фото, дата, стекло.
  Ниже — спокойные белые карточки с данными, без стекла и blur.
- **Одна мысль на блок.** Каждый блок отвечает на один вопрос. Не дробить контент на карточки
  внутри карточек: внутри карточки — списки с разделителями.
- **Статус — словом и формой, цвет вторичен.** Никогда только цветом.
- **Ровность.** Одна высота контролов в ряду, одна вертикаль текста внутри карточек, общие
  нижние линии в сетках. Никаких «на глаз» отступов — только токены.
- **Компактность — через раскладку, не через шрифт.** Не уменьшать текст ниже шкалы; вместо
  этого — две колонки, плотнее отступы, меньше пустых рамок.

## 3. Токены

Все цвета, отступы, скругления, тени — **только через CSS-переменные из `tokens.css`**.
Хардкод hex/px в `app.css` и в JS запрещён (исключение — геометрия значков статусов).
Если нужного токена нет — добавить токен с комментарием, а не писать значение по месту.

### 3.1 Цвет

**Нейтральная база (75–85 % экрана)**

| Токен | Значение | Роль |
|---|---|---|
| `--canvas` | #F7F7F7 | фон страниц |
| `--surface-white` | #FFFFFF | карточки, поля, таблицы, диалоги |
| `--surface-muted` | #EDEDED | вторичные подложки, трек прогресса, disabled |
| `--ink-primary` | #1E1E1E | основной текст |
| `--ink-secondary` | #5E5E5E | подписи, мета, плейсхолдеры |

**Главное действие — «Слива»** (вместо чёрной заливки)

| Токен | Значение | Роль |
|---|---|---|
| `--action-bg` | #5A4458 | основная кнопка, активная вкладка, аватар |
| `--action-bg-hover` | #6B5469 | hover |
| `--action-bg-active` | #4B3A4F | pressed |
| `--action-ink` | #F7F7F7 | текст на сливе (8.2 : 1) |

Слива — только для **одного** главного действия на экране, активной вкладки и аватара.
Не красить ею фоны блоков, заголовки, иконки, текст.

**Акцент интерфейса — глубокая роза** (вместо оранжевого)

| Токен | Значение | Роль |
|---|---|---|
| `--accent-ink` | #8E4B63 | число «Требует внимания», итог сметы, превышение бюджета, выбранная опция |
| `--accent-tint` | #FBEFF2 | подложка выбранной опции, подсветка строки |
| `--accent-line` | #D9A7B6 | контур выбранной опции |

Один акцент на экран. `--brand-accent` (#ED6529, оранжевый) остаётся в токенах только для
маркетинга (лендинг, слайды) — **в интерфейсе приложения не использовать**.

**Статусы** (слово + форма + цвет)

| Статус | Форма значка | Текст | Подложка |
|---|---|---|---|
| Запланировано / Не начато | пустой круг | `--ink-secondary` | `--surface-muted` |
| В работе | полукруг | `--sky-ink` #2F6690 | `--sky-tint` #E6F1FB |
| Готово / Оплачено | круг с галочкой | `--olive-ink` #55662A | `--olive-tint` #EEF3DA |
| Скоро / Ждём / К оплате | треугольник | `--status-amber-ink` #7A5A1E | `--status-amber-tint` #F6EEDC |
| Заблокировано / Просрочено | квадрат с «!» | `--status-blocked` #A13D5A | `--status-blocked-tint` #F9E8EC |

`--status-blocked` (пыльная роза) — также цвет ошибок полей и форм; подложка срочного блока
в карточке — `--urgent-tint-soft` #FBF1F3. Красный #B3261E больше не используется.

**Голубой и оливковый** (`--sky`, `--olive`) — спокойные вторичные цвета брендбука: статусы,
прогресс, блок «Требует внимания» на списке (`--attention-*`). Белый текст на `--sky`,
`--olive` запрещён — только тёмный.

**Линии** — прозрачность #1E1E1E, не отдельные серые:

| Токен | Значение | Где |
|---|---|---|
| `--card-border` | rgba(30,30,30,.08) | контур карточек, списков, панелей |
| `--line-hair` | rgba(30,30,30,.07) | разделители строк внутри карточки, шапка |
| `--line-control` | rgba(30,30,30,.22) | вторичные кнопки, вкладки, радио-опции |
| `--line-control-hover` | rgba(30,30,30,.45) | их hover |
| `--line-dashed` | rgba(30,30,30,.18) | пунктир пустых состояний |
| `--line-strong` | #8C8C8C | **только** границы полей ввода (контраст 3.4 : 1, требование доступности) |

**Стекло поверх фото** — светлое матовое:

| Токен | Значение |
|---|---|
| `--glass-bg` | rgba(255,255,255,.62) + `backdrop-filter: blur(20–24px)` |
| `--glass-border` | rgba(255,255,255,.7) |
| `--glass-ink` / `--glass-ink-2` | #1E1E1E / rgba(30,30,30,.64) |
| `--glass-line` | rgba(30,30,30,.12) |

Тёмного стекла нет.

### 3.2 Типографика

Гарнитура **Involve** (SIL OFL 1.1, woff2 из `web/fonts/`), стек `Involve, Arial, sans-serif`.
Цифры табличные (`font-variant-numeric: tabular-nums` уже на `body`), суммы — вправо.

| Роль | Размер | Вес | Прочее |
|---|---|---|---|
| Заголовок страницы `.page-title` | `--fs-display` clamp(34–52px) | 500 | трекинг −0.025em, lh 1.05 |
| Крупная дата/число | 38–64 px | 400 на белом, 500 на стекле | трекинг −0.04em |
| Заголовок зоны/блока/пустого состояния | `--fs-section` 20px | 500 | трекинг −0.01em |
| Заголовок диалога | 24px | 500 | |
| Заголовок карточки мероприятия | 18px | 500 | до 2 строк |
| Основной текст | 15px, lh 1.5 | 400 | |
| Названия задач, метки полей, кнопки | 14–15px | 500 | |
| Подписи, мета | 13px | 400 | `--ink-secondary` |
| Надзаголовок `.overline` | 12px, прописные | 500 | трекинг 0.1em |
| Статус-метка `.chip` | 11–12px | 500 | |

Веса — через токены `--fw-display`, `--fw-heading`, `--fw-title` (все 500) и `--fw-strong`
(600, редкие выделения в тексте). **Bold 700 в интерфейсе не использовать.** Вес ниже 500
на фото и стекле запрещён. Размер основного текста не уменьшать ради компактности.

### 3.3 Отступы, скругления, глубина

- Шаг 8: `--space-half` 4 · `--space-1` 8 · `--space-2` 16 · `--space-3` 24 · `--space-4` 32 ·
  `--space-6` 48 · `--space-10` 80. Допустимые промежуточные — 12 и 20 px (внутренние ритмы
  строк и карточек), больше никаких.
- Внутренний отступ карточек и зон: 20 px сверху, 24 px по бокам (desktop), 20 px по бокам
  (≤ 599px). Карточка мероприятия: 20 px по бокам.
- Между блоками в колонке — 16 px, между крупными разделами страницы — 32–48 px.
- Скругления растут с поверхностью: поле и маленькая кнопка 12 · кнопка 16 · карточка 24 ·
  hero 32 · pill — только статус-метки, вкладки и метки на фото.
- Тень `--shadow-float` — **только** у всплывающих поверхностей (меню, поповер, диалог).
  У карточек тени нет, при наведении темнеет только контур (`--line-control`).

### 3.4 Контролы

- Основная высота `--control-h` 44px; в ряду фильтров/тулбаре все контролы (вкладки, поиск,
  селект, кнопки) — `--control-h-compact` 40px; маленькие кнопки внутри карточек — 36px
  (зона нажатия ≥ 44 обеспечена псевдоэлементом).
- Фокус клавиатуры: кольцо 2px `--ink-primary` с зазором 2px. У полей ввода — тёмная граница
  2px (граница + `inset` тень 1px) без внешнего кольца.

## 4. Компоненты

**Кнопки** (`.btn`)
- `--primary` — слива, одна на экран, справа в группе.
- `--secondary` — белая, контур `--line-control`, hover — темнее контур (без заливки).
- `--ghost` — без фона и контура, для «Сбросить», «Убрать».
- `--small` — 36px, радиус 12, внутри карточек и строк.
- Текст — глагол в начале, строчными: «Создать свадьбу», «Добавить расход». Стрелка «→» только
  у переходов («Открыть все задачи →», «Смета →»).

**Вкладки** (`.tabs` / `.tab`) — фильтр-метки: pill 40px, неактивные белые с контуром,
активная — слива. На телефоне — одна строка с горизонтальной прокруткой.

**Поля** (`.input`, `.select`, `.field`) — метка сверху (14px/500), граница `--line-strong`,
радиус 12. Селект — без системной стрелки, тонкий шеврон 1.5px справа. Подсказка и ошибка —
13px под полем; пустая строка ошибки не резервирует место. Ошибка — граница и текст
`--status-blocked`, всегда словами.

**Статус-метка** (`.chip` + `.shape`) — см. таблицу статусов. В плотной строке не крупнее
названия задачи.

**Карточка мероприятия** (`.card`)
- Сверху обложка 148px (см. §5): внизу слева статус на белом стекле, внизу справа дата на
  стекле; оба стоят на одной нижней линии, отступ от краёв 16/20px.
- Ниже: мета (13px) → название (18px/500) → блок «Срочно» (подложка `--urgent-tint-soft`,
  радиус 12) → «В работе: …» → «Настройка: N из M» → «Открыть проект →» у нижнего края.
- В ряду карточки одной высоты (`align-items: stretch`), действие прижато вниз.
- Архивная — фото обесцвечено.

**Hero проекта** (`.overview-hero`) — фото на всю ширину, радиус 32. Слева на светлой вуали:
метки (статус, «Свадьба», площадка — одной высоты 24px), название, дата. Справа — стеклянная
панель: крупная дата + сводка «Требует внимания / В работе / Ждём ответа» (кнопки-якоря к
разделам). Меню проекта — круглая стеклянная кнопка в правом верхнем углу. На телефоне
панель уходит под заголовок.

**Зона** (`.zone`) — белая карточка с контуром `--card-border`, заголовок 20px/500, отступ до
содержимого 12px, строки разделены `--line-hair`. Пустая зона (`.zone--compact`) — без карточки,
одна строка: заголовок и текст на одной базовой линии, по вертикали текста соседних карточек.

**Строка задачи** (`.task-row`, `.attention-row`) — от 900px: колонка статусов фиксированной
ширины (240px в списке задач, 200px в блоке внимания), дальше название, мета справа,
стрелка 16px. Уже 900px и в узких колонках — в столбик: статус / название / мета.

**Список подрядчиков, сметы** — строки с разделителями внутри одной карточки, не карточки
в карточке. Цена по базовой линии имени, суммы вправо, табличные цифры.

**Диалог** — белый, радиус 24, тень `--shadow-float`, затемнение `--backdrop`. Поля 28px,
шаг между полями 16px. Стекла нет. «Отмена» слева от главной кнопки. На телефоне — на весь
экран, кнопки растянуты, над ними тонкая линия.

**Пустое состояние** (`.empty`) — белая карточка, пунктир `--line-dashed`, заголовок 20px/500,
одна фраза-направление и действие.

## 5. Обложки проектов

- `web/js/ui/covers.js`:
  - `COVER_LIBRARY` — список путей к картинкам базы;
  - `coverFor(project)` — собственное фото (`project.coverUrl`), иначе картинка из базы по
    стабильному хешу `project.id`. У одного проекта всегда одна и та же обложка — на всех
    устройствах, у всей команды. **Не использовать `Math.random()`.**
  - `coverVariant(project)` — стабильный вариант кадрирования (зеркально / верх / низ), чтобы
    повторы из небольшой базы не выглядели одинаково.
- Везде, где нужна обложка проекта, — только через `coverFor` + `coverVariant`, не напрямую
  через `coverUrl`.
- Добавить картинку: файл в `web/images/covers/` + строка в `COVER_LIBRARY`. Формат — JPG/WebP,
  горизонтальный 16:9, ~1600px по ширине, до ~250 КБ; спокойная правая верхняя часть кадра
  (там стоит дата). Стилистика — пастельные цветы, мягкий свет, без людей в камеру и текста.
- В карточках `loading="lazy"`, `alt=""` (обложка декоративная), пока грузится — фон
  `--surface-muted`.

**Правила стекла:** стекло — только поверх фото. Никогда под таблицами, формами, списками
и в диалогах. Текст на стекле — вес ≥ 500. Если фото слишком пёстрое — плотнее стекло или
светлая вуаль, а не тёмная плашка.

## 6. Раскладка и выравнивание

- Контейнер до 1440px, поля 16 / 32 / 48px (телефон / планшет / desktop).
- **Мои мероприятия:** карточки 1 колонка → 2 от 720px → 3 от 1200px, промежуток 16px.
- **Обзор проекта:** hero, затем от 1024px две колонки `1.6fr / 1fr`: слева «Требует
  внимания», «Дальше», «В работе», «Ждём ответа», «Открыть все задачи»; справа «Настройка
  свадьбы» и «Подрядчики» (колонка `position: sticky`). На телефоне — одна колонка.
- **Правила ровности** (проверять на каждом экране):
  1. В одном горизонтальном ряду — одна высота контролов.
  2. Текст внутри всех карточек в колонке начинается с одной вертикали; элементы на фото —
     на той же вертикали, что текст под фото.
  3. Соседние элементы разного размера выравниваются по базовой линии, а не по центру
     (заголовок + пояснение, имя + цена).
  4. Карточки в ряду одной высоты, действия по нижнему краю.
  5. Колонки таблиц/списков фиксированной ширины, чтобы названия не шли «лесенкой».
  6. Отступы только из шкалы (4, 8, 12, 16, 20, 24, 32, 48, 80).
- Заголовок страницы и главная кнопка — в одной строке, кнопка по центру блока заголовка.
- Мобильная ширина 390px: ничего не обрезается многоточием без необходимости, вкладки
  прокручиваются, диалоги на весь экран.

## 7. Так / не так

| Так | Не так |
|---|---|
| Слива для одной главной кнопки | Слива/чёрный на фонах блоков, несколько тёмных кнопок подряд |
| Роза `--accent-ink` для одного числа-акцента | Оранжевый в интерфейсе, несколько акцентов на экране |
| Статус «Просрочено 2 дня» с формой-квадратом | Красная точка без слова |
| Контур `--card-border`, без тени | Тень у каждой карточки, толстые рамки, `#DEDEDE` вокруг всего |
| Список с разделителями внутри карточки | Карточки внутри карточек, серые подложки под фильтрами |
| Заголовки 500 | Bold 700, заголовки разделов 28px |
| Светлое стекло поверх фото | Стекло на белом фоне, в диалоге, под таблицей; тёмное стекло |
| Компактность — две колонки | Уменьшение шрифта ниже шкалы |
| `coverFor(project)` | `Math.random()` для обложек, прямое чтение `coverUrl` |
| Токены | hex/px в стилях и в JS |
