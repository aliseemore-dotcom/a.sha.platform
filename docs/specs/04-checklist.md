# Следующий экран для Claude Code: выбор задач свадьбы

Создание свадьбы и переход на её страницу уже работают. **Не переделывай создание проекта и существующий экран задач.** Добавь на страницу свадьбы кнопку **«Добавить задачи»** и открывающуюся по нажатию панель с готовыми задачами и чекбоксами. На телефоне панель может занимать весь экран.

## Что видит организатор

1. После создания свадьбы он попадает на её страницу и нажимает «Добавить задачи».
2. В панели видит сгруппированный список ниже. Отмечает нужные пункты. Внизу — кнопка «Добавить N задач». До нажатия на неё ничего не сохраняется.
3. Если дата свадьбы известна, рядом с каждой выбранной задачей показан **примерный дедлайн**; его можно поменять или убрать до добавления. Подпись: «Сроки примерные — их можно изменить». Если дата свадьбы неизвестна, задачи добавляются без сроков.
4. После сохранения выбранные задачи появляются на странице свадьбы в разделе задач и в существующем общем списке задач проекта. Карточка этой свадьбы на странице «Мои мероприятия» обновляет своё обычное краткое превью задач. Не выводи в карточку весь список.
5. Панель можно открыть ещё раз, чтобы добавить другие пункты. Уже добавленные обозначены «Добавлено» и не создаются повторно. Отдельно остаётся возможность создать свою задачу через существующую форму.

## Список для первого MVP

| Раздел | Задачи |
|---|---|
| Начало | Заполнить бриф пары; согласовать формат свадьбы; определить ориентир бюджета |
| Площадка | Подобрать площадки; подтвердить площадку |
| Подрядчики | Определить нужных подрядчиков; согласовать подрядчиков |
| Гости | Составить список гостей; отправить приглашения; подготовить рассадку |
| Подготовка дня | Согласовать меню; подготовить тайминг; подтвердить финальный тайминг и договорённости |

Это черновой набор. Не проставляй автоматически ответственных и не отмечай эти задачи выполненными.

## Примерные сроки

Для MVP распределяй выбранные задачи между сегодняшним днём и датой свадьбы: задачи «Начало» — примерно в первые 10–20% оставшегося времени, «Площадка» и «Подрядчики» — 20–50%, «Гости» — 30–85%, «Подготовка дня» — 50–95%. Конкретный день внутри диапазона можно выбрать случайно **один раз при добавлении**. Дата сохраняется как обычный редактируемый срок задачи и не меняется при повторном открытии страницы. Не назначай дату позже свадьбы. Если до свадьбы осталось всего несколько дней, допустимо несколько задач на один день. Если дата уже прошла, автоматические сроки не ставь.

Эти интервалы временные: после тестов с организаторами мы уточним реальные сроки.

## Проверка результата

Создай тестовую свадьбу, отметь три задачи, измени один предложенный срок и добавь их. Убедись, что они видны на странице свадьбы, в общем списке задач проекта и учтены в краткой карточке на «Моих мероприятиях». Повторное открытие панели и повторный клик не должны создавать копии. Существующие задачи проекта не удаляй и не перезаписывай.

Переиспользуй текущие модели, стили и способы сохранения задач. Если в коде уже есть автоматическое добавление стартовых задач при создании свадьбы, замени его выбором через эту панель для новых проектов, сохранив задачи ранее созданных проектов.
